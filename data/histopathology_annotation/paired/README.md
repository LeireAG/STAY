# Histopathology annotations: paired

Paired STAY vs standard sections of four patients (preprocessing, Figures 3, 6 and 7).

## Layout

`<sample_id>/` with `json/` (QuPath annotations, all layers) and `csv_files/` (spot-level `*_epithelial_reworked.csv`, `*_immune_reworked.csv`, `*_stroma_reworked.csv`, `*_additional_features_reworked.csv`).

Sample IDs: `Patient_<n>_STAY` / `Patient_<n>_standard` (Patient 1-4). See `resources/sample_list.csv`.
