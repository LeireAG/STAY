# Histopathology annotations: STAY

STAY cohort of the detachment analysis (Figure 2).

## Layout

`<sample_id>/` with `geojson/<sample_id>_epithelial.geojson` (QuPath) and `csv/<sample_id>_epithelial.csv` (spot-level epithelial annotation).

Sample IDs: `P01` ... `P32` (`P29_1`, `P29_2`: two sections of P29). See `resources/sample_list.csv`.
