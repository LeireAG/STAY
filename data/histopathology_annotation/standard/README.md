# Histopathology annotations: standard

Standard-protocol cohort of the detachment analysis (Figure 2).

## Layout

`<sample_id>/` with `geojson/<sample_id>_epithelial.geojson` (QuPath) and `csv/<sample_id>_epithelial.csv` (spot-level epithelial annotation).

Sample IDs: `S01` ... `S20`. See `resources/sample_list.csv`.
