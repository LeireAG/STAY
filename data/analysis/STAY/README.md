# Intermediate analysis results: STAY

STAY cohort of the detachment analysis (Figure 2). Samples are listed in `resources/sample_list.csv`.

## Layout

One folder per analysis, e.g. `detachment_score/<sample_id>.csv` (STAY, standard) or `crop_images/<sample_id>/` (paired).
