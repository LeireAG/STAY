Processed data (https://doi.org/10.5281/zenodo.23558413) for the STAY study: "Adapting spatial transcriptomics to FFPE tissue sections prepared with routine histology workflows in clinical settings".

Code: https://github.com/LeireAG/STAY

Files

Each zip holds one data type for one cohort. Inside, paths start at the repository root (data/<type>/<cohort>/...).

ZipContents
spaceranger_paired.zipSpace Ranger output, paired cohort
spaceranger_standard.zipSpace Ranger output, standard cohort
histopathology_annotation_paired.zipQuPath annotations and spot-level annotations, paired cohort
histopathology_annotation_standard.zipQuPath annotations and spot-level epithelial annotations, standard cohort
analysis_paired.zipCropped H&E images and shifted spot coordinates, paired cohort
analysis_STAY.zipPer-spot detachment scores, STAY cohort
analysis_standard.zipPer-spot detachment scores, standard cohort
r_objects_paired.zippaired_object.rds: final Seurat/semla object, paired cohort
r_objects_lymph_node.ziplymph_node_object.rds: final Seurat/semla object, lymph node cohort

Raw data (data/raw_data/) is deposited separately: RAW_DATA_ACCESSION

STAY cohort and lymph node data (raw data, Space Ranger output, annotations): https://doi.org/10.6019/S-BIAD3080 and https://doi.org/10.5281/zenodo.18917100

How to use

git clone https://github.com/LeireAG/STAY STAY
cd STAY
# download the zips into this folder, then:
for f in *.zip; do unzip -n "$f"; done

Every file lands in its correct data/ folder. Then follow the repository README to set up the environments and run the analysis.
